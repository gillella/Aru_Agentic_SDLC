Bootstrap a new repository under Aru_Agentic_SDLC governance.

1. Read and follow `$ARU_SDLC_HOME/skills/init-agent-project/SKILL.md`.
2. Gather project name, stack, test runner, and visibility (default private).
3. Run `python3 "$ARU_SDLC_HOME/scripts/init_project.py" --name <NAME> --private --create-board`
   (adjust flags as needed).
4. Confirm `AGENTS.md`, CI, labels, and the project board exist before filing issues.
